Рабочая папка - папка, в которой я напрямую работаю с файлами проекта

Индекс - область, в которой я вношу изменения, предназначенные для следующего коммита

Коммит - контрольная точка в проекте

Git - программа для контроля версий, которая хранит историю изменений проекта. С ней можно работать локально

GitHub - веб-сервис для размещения Git-репозиториев и совместной работы с ними

'git status' показывает состояние рабочей папки и индекса: какие файлы изменены, подготовлены к коммиту или ещё не отслеживаются

'git diff' показывает незаписанные в индекс изменения относительно индекса

'git diff --staged' показывает изменения, добавленные в индекс, относительно последнего коммита

Ветка - отдельная линия разработки, указывающая на коммит. Новый коммит в текущей ветке передвигает указатель этой ветки вперёд

Слияние объединяет изменения из другой ветки с текущей. Если изменения не конфликтуют, Git может выполнить слияние автоматически
