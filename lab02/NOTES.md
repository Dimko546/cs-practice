Рабочая папка - папка, в которой я напрямую работаю с файлами проекта

Индекс - область, в которой я вношу изменения, предназначенные для следующего коммита

Коммит - контрольная точка в проекте

Git - программа для контроля версий, которая хранит историю изменений проекта. С ней можно работать локально

GitHub - веб-сервис для размещения Git-репозиториев и совместной работы с ними
