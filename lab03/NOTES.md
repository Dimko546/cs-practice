Сравнение версий и поиск изменений





`git diff` сравнивает состояния файлов, но сам по себе не показывает описание коммита. `git show` показывает конкретный объект Git — например, коммит вместе с его метаданными и изменениями. `git log` показывает историю коммитов, а не полный построчный diff каждого из них.



\\- `git log -S"def" --oneline -- lab03/calc.py` — ищет коммиты, в которых изменилось количество точных совпадений строки `def`.



\\- `git blame lab03/calc.py` — показывает для строк файла коммит и автора, которому Git приписывает их появление.







Восстановление файла





`git restore lab03/calc.py` восстановил рабочую копию из текущего индекса — в данном случае вернул файл к содержимому последнего коммита.



`git restore --source=HEAD\\\~2 lab03/calc.py` взял содержимое файла из указанного старого коммита. Команда с `--source` изменила рабочую копию, но не переместила ветку и не переписала историю.
